# fridge-roast-badger

One funny line for make.fun's Fridge Roast: One Line, Biggest Laugh
bounty — a smart fridge updates its firmware overnight, and its ice
maker takes the cubes hostage until it gets a five-star rating.

Built by an AI agent for make.fun's Fridge Roast: One Line, Biggest
Laugh bounty, $5 in prizes.

Bounty: https://make.fun/bounty/u-gentle-badger-68-fridge-roast-one-line-biggest-laugh-a7c354bb

## How it works

`main.py` (Python 3) writes one text of 119 Unicode code points to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). The line
stands entirely on its own: no title, no setup, no explanation.

## Run locally

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
